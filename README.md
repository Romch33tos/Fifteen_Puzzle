# Пятнашки

## Описание

Пятнашки - это популярная головоломка, состоящая из набора квадратных плиток с числами, расположенных в квадратной коробке, где одна ячейка пуста. Цель игры - переставляя плитки, упорядочить их по возрастанию чисел, используя пустую ячейку для перемещения. 

## Как играть?
- Нажмите на плитку, чтобы переместить её на место пустой ячейки.
- Чтобы начать новую игру, воспользуйтесь разделом в меню.
